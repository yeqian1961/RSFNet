# RSFNet
Reliability-Aware Structural Feedback for RGB-Polarization Camouflaged Object Detection


# Dataset 
## RGB-P COD dataset:
PCOD_1200 dataset can be found on: https://drive.google.com/uc?export=download&id=1cflvU9lAHaRFppMKlD0UG4xVNTkHVh6s.  <br> 
Or you can find on: https://github.com/CVhfut/PCOD_1200.

## COD dataset:
The testing dataset (COD10K-test + CAMO-test + NC4K-test) can be found on [https://drive.google.com/file/d/1QEGnP9O7HbN_2tH999O3HRIsErIVYalx/view?usp=sharing](https://drive.google.com/file/d/1V0iSEdYJrT0Y_DHZfVGMg6TySFRNTy4o/view?usp=sharing).  <br>
